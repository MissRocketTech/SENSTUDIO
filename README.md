# ⚡ SEN Studio — Web & Digital Branding

Sitio web oficial y portfolio digital de **SEN Studio**, enfocado en diseño UI/UX, desarrollo web fullstack a medida y soluciones digitales de alto impacto.

---

## 🛠️ Stack Tecnológico

- **Frontend:** [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Diseño & UI:** [Figma](https://www.figma.com/) (Tokens de diseño personalizados)
- **Control de Versiones & CI/CD:** Git & GitHub

---

## 📂 Estructura del Proyecto

```text
src/
├── assets/          # Logotipos, iconos SVG y recursos gráficos
├── components/      # Componentes modulares y reutilizables
│   ├── common/      # Botones, tarjetas, badges, modales
│   ├── layout/      # Navbar, Footer, Contenedores
│   └── sections/    # Hero, Servicios, Portfolio, Contacto
├── styles/          # Variables CSS, reset y tokens de diseño
├── types/           # Interfaces y tipos de TypeScript
├── App.tsx          # Componente principal
└── main.tsx         # Punto de entrada de la aplicación
